- Commit: `c1e3e418f4cccf0b78e1b6088879b1989e8c0fed` (full 40-character commit SHA — never a branch or tag name)

Steps:

1. If either value above still contains `{{`, stop and tell the owner the template is not released yet.
2. Check the commit is exactly 40 lowercase hex characters. Otherwise stop.
3. Tell the owner what will be installed (the file list below) and from where, and ask for OK.
4. Download each file to a fresh staging directory `~/.body-brief-staging/` (mode 0700) from `<raw base>/<commit>/<path>` over HTTPS. Use only Python's standard library or curl; install nothing else.
5. Verify with `sha256sum -c` against the manifest below (run inside the staging dir). If **any** line fails or a file is missing: delete the staging dir, install nothing, and tell the owner which path failed.
6. Run the offline tests in staging: `python3 -m unittest discover -s tests`. If they fail, stop.
7. Move the verified tree to `~/body-brief/` (replace the previous version only after verification), `chmod 700 ~/body-brief`, files 0600 (scripts are run with `python3`, no execute bit needed). Delete the staging dir.
8. Do not touch `~/.secrets/whoop/` or `~/health/whoop/` during install or update.
9. Report: commit installed, number of files verified, test result.
